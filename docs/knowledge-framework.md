# 系统架构设计师知识体系框架

> 基于《系统架构设计师教程第2版》(清华大学出版社, 2022)，全书20章，分上下两篇。
> 考试三科：综合知识(75选择题/150min) · 案例分析(5选3/90min) · 论文写作(4选1/120min)

  - 1.1.4 软件架构的发展未来

  - 1.2.1 架构设计师的定义、职责和任务
  - 1.2.2 架构设计师应具备的专业素质
  - 1.2.3 架构设计师的知识结构
- 1.3 如何成为一名好的系统架构设计师
  - 1.3.1 如何衡量一名优秀架构设计师
