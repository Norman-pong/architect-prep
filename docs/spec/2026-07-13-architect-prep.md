# 系统架构师备考平台 Spec

> 修改记录：执行 `lore log docs/spec/2026-07-13-architect-prep.md`
> 来源：用户需求讨论
> 接力状态：已提纯 PRD

## 1. 问题陈述

备考「系统架构设计师」(软考高级) 缺少一个集成知识体系学习与刷题练习的一体化 Web 平台。现有方案要么是纯 PDF 资料（如 xxlllq/xiaomabenten 仓库），要么是在线平台不开放数据（如软考达人），缺少可自托管、数据可控的备考工具。

## 2. 目标用户

| 用户角色 | 描述                           | 核心诉求                                   |
| -------- | ------------------------------ | ------------------------------------------ |
| 备考考生 | 准备系统架构设计师考试的工程师 | 知识体系系统学习 + 历年真题刷题 + 错题回顾 |
| 多用户   | 不同考生需要独立进度           | 个人错题本、收藏、做题记录                 |

## 3. v1 功能边界

### 3.1 v1 必做

| 功能           | 解决什么         | 验收标准                  |
| -------------- | ---------------- | ------------------------- |
| 知识体系浏览   | 教材知识点结构化 | 20 章知识点可按层级浏览   |
| 题库练习       | 真题/模拟题刷题  | 支持选择题练习+判分+解析  |
| 错题本         | 错题复习         | 自动收集错题，可重做      |
| 邮箱验证码登录 | 无密码认证       | SMTP 发送验证码，JWT 会话 |

### 3.2 v1 推迟

| 功能         | 推迟理由             | 何时再评估 |
| ------------ | -------------------- | ---------- |
| 模考计时     | 非核心，先做章节练习 | v2         |
| 学习进度统计 | 需要足够做题数据     | v2         |
| 论文写作辅助 | AI 能力，复杂度高    | v3         |

### 3.3 永远不做

| 方向      | 不做原因           |
| --------- | ------------------ |
| 视频课程  | 非文本学习工具定位 |
| 社区/论坛 | 非备考工具核心     |

## 4. 核心场景

1. **知识学习**：打开平台 → 浏览章节目录 → 点击章节查看知识点详情
2. **刷题练习**：选择章节 → 逐题作答 → 提交查看正确率 → 错题自动进入错题本
3. **错题复习**：打开错题本 → 筛选错题 → 重做 → 查看解析

## 5. 验收标准

- [ ] 邮箱验证码可发送并登录
- [ ] 知识体系 20 章可浏览
- [ ] 题目可导入并练习
- [ ] 做题记录和错题本正常工作

## 6. 非功能需求

| 维度 | 需求                | 备注           |
| ---- | ------------------- | -------------- |
| 性能 | 页面加载 <2s        | SPA 静态资源   |
| 安全 | JWT 认证            | 验证码 60s TTL |
| 部署 | Docker Compose 一键 | SQLite 嵌入式  |
