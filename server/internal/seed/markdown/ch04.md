## 信息安全三要素

信息安全包括五个基本要素：**机密性、完整性、可用性、可控性与可审查性**[^1]。

- **机密性**：确保信息不暴露给未授权的实体或进程
- **完整性**：只有得到允许的人才能修改数据，并且能够判别出数据是否已被篡改
- **可用性**：得到授权的实体在需要时可访问数据
- **可控性**：可以控制授权范围内的信息流向及行为方式
- **可审查性**：对出现的信息安全问题提供调查的依据和手段

信息安全的范围包括设备安全、数据安全、内容安全和行为安全。其中数据安全又包括数据的秘密性、完整性和可用性三个方面[^2]。

信息安全系统的组成框架通常由**技术体系、组织机构体系和管理体系**共同构建。技术体系涉及基础安全设备、计算机网络安全、操作系统安全、数据库安全和终端设备安全等多方面技术。管理体系由法律管理、制度管理和培训管理三部分组成，所谓"三分技术，七分管理"[^3]。

我国政府高度重视信息安全，2014年中央成立了中央网络安全与信息化领导小组，集中领导与规划我国的信息化发展与信息安全保障。习近平主席指出："没有网络安全就没有国家安全，没有信息化就没有现代化。"网络安全和信息化是事关国家安全和国家发展、事关广大人民群众工作生活的重大战略问题[^4]。

## 对称密钥加密

对称密钥加密算法中加密密钥和解密密钥相同，称为共享密钥算法。主要代表算法包括：

**DES（Data Encryption Standard）**：1977年由美国NSA制定，明文分成64位块，进行16次变换，使用56位密钥。由于密钥长度较短，存在安全争议。三重DES（Triple-DES）使用两把密钥进行三次DES加密，有效密钥长度112位[^5]。

**IDEA**：1990年由来学嘉和Massey提出，使用128位密钥，把明文分成64位块进行8轮迭代加密，加密速率高且对密码分析具有很强的抵抗能力[^6]。

**AES（Advanced Encryption Standard）**：2000年NIST选定Rijndael算法为正式标准，支持128、192和256位三种密钥长度，能够在世界范围内免版税使用[^7]。

对称加密的优点是加密解密速度快，适合大量数据加密；缺点是密钥分发困难，N个用户需要N(N-1)/2个密钥[^8]。

## 非对称密钥加密

非对称加密算法中加密密钥和解密密钥不同，称为公钥加密算法。1976年，斯坦福大学的Diffie和Hellman提出了使用不同密钥进行加密和解密的公钥加密思想[^9]。

**RSA算法**：由Rivest、Shamir和Adleman提出，其安全性基于大素数分解的困难性。算法选择两个大素数p和q，令n=pq，公钥为(e,n)，私钥为(d,n)。加密时计算 $C = P^e \pmod{n}$，解密时计算 $P = C^d \pmod{n}$。分解200位的数需要40亿年，分解500位的数需要$10^{25}$年[^10]。

非对称加密解决了密钥分发问题，可实现：

- **保密通信**：用公钥加密，私钥解密
- **数字签名**：用私钥加密，公钥解密[^11]

由于公钥加密速度较慢，实际应用中常采用**公钥加密分配单钥密码体制的密钥**：先用公钥密码建立安全信道，再通过对称密码进行大量数据加密[^12]。

## 数字签名技术

数字签名与人们手写签名的作用一样，向通信双方提供服务，使得A向B发送签名的消息P时达到以下目标：B可以验证消息P确实来源于A；A以后不能否认发送过P；B不能编造或改变消息P[^13]。

可用的数字签名应保证五个条件：签名是可信的、不可伪造、不可重用、签名的文件不可改变、签名不可抵赖[^14]。

**基于公钥的数字签名**是最常用的实现方式：

- 发送方A使用自己的私钥对消息（或消息的Hash值）进行签名
- 接收方B使用A的公钥验证签名
- 如果A方否认，B可以出示签名并用A的公钥解密验证
- 如果B篡改消息，A可要求B出示原签名，B无法提供[^15]

对长文件签名时，通常和单向Hash函数一起使用，只对文件的Hash值签名，大大提高计算速度，且签名和文件可以分开保存[^16]。

## 访问控制模型

访问控制是指主体依据某些控制策略或权限对客体本身或其资源进行的不同授权访问，包括三个要素：主体（Subject）、客体（Object）和控制策略[^17]。

访问控制的实现技术包括：

- **访问控制矩阵（ACM）**：以主体为行索引、客体为列索引的矩阵，记录访问权限。实现简单但存储开销大
- **访问控制表（ACLs）**：按列保存访问矩阵，每个客体有一个访问控制表，是目前最流行、使用最多的技术
- **能力表（Capabilities）**：按行保存访问矩阵，每个主体有一个能力表
- **授权关系表**：对应访问矩阵中每一个非空元素，安全数据库系统通常采用此方式[^18]

《计算机信息系统安全保护等级划分准则》（GB 17859-1999）规定了计算机系统安全保护能力的五个等级：用户自主保护级、系统审计保护级、安全标记保护级、结构化保护级和访问验证保护级[^19]。

## 常见攻击与防御

拒绝服务攻击（DoS/DDoS）是人为或非人为发起的行动，使主机硬件、软件或两者同时失去工作能力。分布式拒绝服务攻击（DDoS）采用三级结构：Client（客户端）、Handler（主控端）和Agent（代理端），克服了传统DoS受网络资源限制和隐蔽性差的弱点[^20]。

主要攻击类型及防御：

| 攻击类型         | 原理                                             | 防御措施                                 |
| ---------------- | ------------------------------------------------ | ---------------------------------------- |
| **SYN Flooding** | 利用TCP三次握手，发送大量伪造SYN包填满半连接队列 | 修改注册表SynAttackProtect等键值         |
| **ARP欺骗**      | 伪造ARP应答，将目标MAC地址改为攻击者地址         | 固化ARP表、使用ARP防护软件               |
| **DNS欺骗**      | 冒充DNS服务器回复虚假IP地址                      | 被动监听检测、虚假报文探测、交叉检查查询 |
| **IP欺骗**       | 伪造源IP地址，利用TCP三次握手漏洞                | 删除hosts.equiv文件、设置防火墙过滤      |
| **端口扫描**     | 尝试与目标主机端口建立连接探测开放端口           | 加强数据包特征识别、设置防火墙监视       |

系统漏洞扫描分为基于网络的扫描（通过网络远程扫描）和基于主机的扫描（在目标系统安装代理）。风险评估的基本要素为脆弱性、资产、威胁、风险和安全措施[^21]。
